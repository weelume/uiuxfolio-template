# UIUXfolio Template

独立 Next.js / React 设计师作品集工程。完整规则见 [.tpl/README.md](.tpl/README.md)。

Node 22.13.1 / pnpm 12.10.1。运行 `pnpm install --frozen-lockfile`、`pnpm dev`，访问 http://127.0.0.1:43122。中文 `/`，英文 `/en`。Ctrl+C 停止本工程服务。

`pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build` 验证；生产预览 `pnpm start`；共享包 `pnpm bundle`。真实 Git 仓库：https://github.com/weelume/uiuxfolio-template；参考素材再分发许可未确认，保持本地评审和 listed=false。
